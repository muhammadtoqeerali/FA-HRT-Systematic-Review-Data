# FA-HRT systematic review data

This repository accompanies *Fall-Aware Human–Robot Teaming: A Systematic Review of Simulation, Perception, Prediction, and Control*.

It provides the extracted evidence and supporting records for 102 publications (P001–P102): 11 in simulation/modeling, 26 in perception/detection-response, 9 in prediction/anticipation, and 56 in control/assistance/prevention/response.

## Notes

Each P-code identifies a publication, not an independent experiment. P006/P058 and P019/P022 share reported primary results; the 102 publications therefore correspond to 100 non-repeated primary-result identifiers. Research-family links do not necessarily imply repeated experiments.

The search workbooks report the published search logic and selection totals. The export folders contain saved database results, not a complete record of the exact database-specific query syntax or each individual screening decision. The integration-audit workbook contains published summary counts rather than publication-level C1–C5 decisions.

Blank or unreported study details should not be interpreted as negative findings. Publisher PDFs are not included; available DOI and source links identify the original publications.
